HOW TO RUN
================================================================================

METHOD 1: Quick Start
  1. Ensure backend is running:
     cd backend
     .venv\Scripts\activate
     uvicorn app.main:app --host 0.0.0.0 --port 8000

  2. Run mobile app:
     cd sahayak_mobile
     flutter run

METHOD 2: Use Batch Scripts
  - Backend: start_complete_backend.bat
  - Mobile: START_MOBILE_APP.bat

METHOD 3: Custom Backend URL
  flutter run --dart-define=API_BASE_URL=http://YOUR_IP:8000
